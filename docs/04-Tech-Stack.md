# 技术栈选型说明

## 1. 编程语言
**Java 8 / Java 11 / Java 17**：作为企业级应用开发的主流语言，提供完整的生态系统和高性能的多线程支持。

## 2. 后端核心框架
**Spring Boot**：用于快速构建生产级别的后端微服务应用程序，内嵌 Tomcat 容器，能够达到快速启动和部署的目的。
**Spring MVC**：提供强大的 RESTful API 构建支持，处理 Web 层的 HTTP 请求与响应。
**MyBatis / MyBatis-Plus**：作为持久层框架，具有高效的 SQL 映射能力以及丰富的 CRUD 方法封装，简化数据库交互。

## 3. 中间件与组件
**MySQL**：关系型数据库选型，用于提供强一致性的存储服务并满足事务支持场景。
**Redis**：分布式缓存中间件，用于高频数据的读缓存（如商品详情页面）、登录态 (Token) 保留与共享、以及分布式锁的实现。
**Nginx**：作为反向代理服务器以及静态资源服务器，实现动静分离以及对后端多实例的负载均衡。
**(可选) ElasticSearch**：用于构建海量商品数据的高效文本检索与过滤服务。
**Docker & Docker-compose**：用于环境的一键构建与隔离，便于在不同开发与测试环境中无缝运行。

## 4. 前端架构 (简单实现)
**HTML5 + CSS + JavaScript**：采用原生的 Web 技术编写简单的动静分离页面，为了方便直接被 Nginx 托管。也可以选择 Vue 结合 Axios 完成与后端的交互。
